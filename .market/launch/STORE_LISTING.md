# EU Safety Gate & Recall API (GPSR, RAPEX & EAN Compliance)

## Warum diese API?
Seit Inkrafttreten der EU-Produktsicherheitsverordnung (GPSR) im Dezember 2024 werden nicht-konforme Produkte auf Marktplätzen wie Amazon und eBay sofort gesperrt.

Diese API ermöglicht E-Commerce-Händlern, Compliance-Beauftragten und automatisierten KI-Agenten die sekundenschnelle Verifikation von Produktkatalogen gegen die offizielle EU Safety Gate (RAPEX) Datenbank.

### Features
- 🚀 **Batch EAN Screening:** Prüfe bis zu 500 Barcodes in einem einzigen Request.
- 🧪 **REACH & Chemical Alerts:** Automatische Erkennung verbotener chemischer Substanzen.
- 🤖 **Model Context Protocol (MCP):** Vollständig kompatibel mit Claude Desktop, Cursor und autonomen Agenten.
- 💰 **Faires PPE-Pricing:** $0.05 Start-Gebühr + $1.90 pro 1.000 Alerts.
